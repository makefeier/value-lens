三模式自动判定（可组合）：

| 模式 | 触发 | 主输出 |
|---|---|---|
| **单物估值** | 一个具体的人/事/物 | 七层剖面 + 处置建议 |
| **买卖决策** | "值不值得买 / 该不该卖" | 处置六账 |
| **投资持有** | "现在进 / 要不要撤" | 共识温度 + 期权审计 + 撤出条件 |

访谈最小集（并入首次回复，≤3 问）：**主体**（你是什么身份？自用/转卖/收藏/旁观——决定权重）+ **时间窗**（什么时候要用这笔价值？决定半衰期相关性）+ **已投入**（已经花了多少？只用于沉没成本隔离，不参与决策）。

**处置六账**（买卖决策模式主输出，逐笔算）：

1. **买入账**：到手价 + 隐性成本（配件、维护、学习、机会成本——这笔钱不买它还能干什么）。
2. **持有账**：每年空间/保养/保险/注意力成本，乘以预计持有年数。
3. **留用账**：剩余效用（半衰期校正后）+ 系统协同 + 情感自留值（只对自己有效）。
4. **卖出账**：可成交价（按真实成交，不按挂价）− 平台折价 − 时间沟通成本。
5. **扔弃账**：腾出的空间与注意力 + 处置成本（回收、搬运、环境代价）。
6. **机会账**：这笔钱/空间/注意力的最佳替代用途值多少——所有账最后都要和它比。

输出格式：每笔账一行，数字带三色置信标签；六账合称**处置账本**。结论只允许六种——**买 / 卖 / 留 / 扔 / 投 / 撤**，附一句触发条件（例："跌破 X 元再买""周末前没成交就撤"）。
